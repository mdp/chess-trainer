# Opening data

`openings.tsv` is generated from the `a.tsv` through `e.tsv` files in
[`lichess-org/chess-openings`](https://github.com/lichess-org/chess-openings).

The source dataset is released under the CC0 Public Domain Dedication. It
contains ECO codes, names, and canonical move sequences. The trainer uses it
only for optional post-exercise context; concepts and engine scoring remain
independent of opening labels.
